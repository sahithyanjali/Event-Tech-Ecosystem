# Event-Tech-Ecosystem

An AI-powered event management platform designed to streamline event planning, attendee registration, engagement, communication, and operational workflows through an integrated technology ecosystem.

## Overview

Event-Tech-Ecosystem simplifies the complete event lifecycle by providing organizers with a centralized platform to create, manage, and monitor events. The system leverages modern web technologies and Google Gemini AI capabilities to enhance event operations, automate workflows, and improve attendee experiences.

## Key Features

### Event Management

* Create, edit, and manage events
* Configure event schedules and agendas
* Monitor event status and participant activity

### Registration & Attendee Management

* Online attendee registration

## System Workflow

1. Organizers create and publish events.
2. Attendees register through the platform.
3. Event information is processed and stored.
4. AI-powered services assist users and organizers.
5. Notifications and reminders are automatically generated.
6. Analytics dashboards provide real-time event insights.

## Installation

### Prerequisites

* Node.js
* Google Gemini API Key

### Setup

```bash
git clone <repository-url>
cd event-tech-ecosystem
npm install
```

Create a `.env.local` file:

```env
GEMINI_API_KEY=your_api_key_here
```

Start the development server:

```bash
npm run dev
```

## Deployment

Build the application:

```bash
npm run build
```

Deploy the generated build files to Netlify or any cloud hosting provider.
